# PoE Layouts (web)

Path of Exile campaign zone layouts, hints and a run timer. Open the page in Chrome or Edge,
click **Choose Client.txt** and pick `Path of Exile/logs/Client.txt`. The log is read locally;
nothing is uploaded.

Generated build of poe-layouts. Data sources and their MIT licenses: [LICENSES.txt](LICENSES.txt).
